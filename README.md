# MiniStore

A clean, modern shopping interface built with React and Vite. This project demonstrates a polished e-commerce UI with search, filtering, and a seamless cart experience.

## Features

- **Product Browsing**: Clean grid layout with hover effects and product details.
- **Smart Filtering**: Real-time search and sorting to find exactly what you need.
- **Dynamic Cart**: Add items, adjust quantities, and see stock limits instantly.
- **Responsive Design**: Looks great on desktop and mobile.
- **Smooth Interactions**: Toast notifications and modal views for a premium feel.

## Tech Stack

- **React 18** (Vite)
- **CSS Modules** for scoped, maintainable styling
- **Context API** for state management (Cart & Toast)
- **Hooks** for logic reuse

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. Open your browser and head to the local URL shown in the terminal!

## Notes

This was built to showcase a specific set of UI/UX patterns—specifically around preventing re-renders and handling complex state without reaching for heavy external libraries like Redux. Enjoy looking around!
